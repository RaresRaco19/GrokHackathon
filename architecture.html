Assess path

The model decides. Python only runs tools and rejects illegal output (no MCP call, invented PX-*, payout amount).

  1. Load inquiryReport from fnol.json and/or a free-text question. Prompt from AGENTS.md.
  2. Grok tool loopFirst turn tool_choice=required. lookup_rule / list_rules execute on local MCP.
  3. MCP passages return to GrokThe quote must be a verbatim lookup_rule line. Policy is not stuffed into the prompt.
  4. JSON decisionopen / hold / refuse + rule_id + quote. Guidance: flood refuse, no photos hold, glass+photos open, “will we pay?” PX-NO-PAY.
  5. Validator gateMCP was called, quote ⊆ tool result, known PX-*, no $ amount. Repair once, else 502.
  6. Cache + live-opsGET /api/queue does not call Grok. Confirm is still a human click.

Live-ops

Who clicks before it sends: a human on POST /api/confirm. The agent stops at the decision block.

GET

/api/queue — cached decisions only. Does not call Grok. needs_assess until POST assess.

POST

/api/assess — Grok + MCP tools. Logs refuse once.

POST

/api/confirm — mints FNOL-{id}-{UTC} on open only. CL-04 → 400 refuse is not sent.

POST

/api/undo — restore draft, clear claim number.

GET

/api/log — JSONL. No amount, payout, or $ keys.

GET

/api/health — MCP reachable via list_rules.
